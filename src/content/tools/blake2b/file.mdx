## Verifying a file with BLAKE2b

Drop a file above for its 128-character BLAKE2b digest. The file is streamed through the hash
in your browser and never uploaded.

## The fast option that is also well established

BLAKE2b's pitch is that it is faster than MD5 while carrying the security margin of a SHA-3
finalist. That is not marketing: the design took BLAKE, which had a large margin, and spent
part of it on fewer rounds and a simpler schedule.

Unlike newer fast hashes, it has been standardised since 2015, ships in GNU coreutils as
`b2sum`, and is embedded in Argon2, libsodium and WireGuard. If you want speed without
explaining a young algorithm to a reviewer, this is the one.

## Matching the command line

```
b2sum bigfile.tar
openssl dgst -blake2b512 bigfile.tar
```

Both produce the digest shown above. Note that `b2sum` can be asked for shorter digests with
`-l`; this page computes the full 512-bit output.
