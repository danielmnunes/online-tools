## Highlighting without a server

The grammar runs in the tab. Tokens become spans with classes, coloured from this site's semantic palette so both themes stay readable. There is no network request at highlight time, and there is no third-party stylesheet.

Auto-detect is a convenience. It scores the registered languages and picks the best; it cannot invent a language that is not in the list, and it can pick the wrong one among those that are. When the answer matters, set the language.
