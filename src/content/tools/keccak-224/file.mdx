## Hashing a file with Keccak-224

Drop a file above for its 56-character Keccak-224 digest, computed with the original padding
rule. The file is streamed through the hash locally and never uploaded.

## Why the original padding still matters

Between Keccak winning the SHA-3 competition in 2012 and FIPS 202 arriving in 2015, real
software shipped against the submitted specification. Those implementations compute what this
page computes. Anything written against the standard computes SHA3-224.

Neither is wrong, and neither is more secure. The change existed to keep SHA-3's several
modes in separate domains, not to fix a weakness.

## Reproducing an old digest

This page's reason to exist is matching a value from a pre-2015 tool or a test vector labelled
"Keccak". If you are producing a new checksum, use SHA-256 — or SHA3-224 if the length is
what you need.
