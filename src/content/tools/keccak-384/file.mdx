## Hashing a file with Keccak-384

Drop a file above for its 96-character Keccak-384 digest, computed with the original
competition padding. Everything runs in your browser; the file is streamed and never
uploaded.

## Original versus standardised, once more

The SHA-3 standard differs from the Keccak submission in exactly two bits appended before
padding. That was enough to split the ecosystem into two families of function with nearly
identical names, and it is why a page like this exists at all.

For a 384-bit digest in anything new, SHA3-384 is the name current specifications mean. This
page is for matching something older.

## Speed expectations

Keccak-384 absorbs 104 bytes per permutation call. On a large file that is noticeably slower
than Keccak-256's 136 and dramatically slower than a hardware-accelerated SHA-256 — which
this page cannot reach from JavaScript in any case.
