## Verifying a file with SHA-224

Drop a file above and its 56-character SHA-224 digest appears. The file is read through the
browser's File API and streamed through the hash; nothing is uploaded, and there is no size
limit beyond how long you are willing to wait.

## A digest size chosen to match something else

SHA-224 exists because 224 bits gives 112 bits of collision resistance, which is the security
level of Triple DES and 2048-bit RSA. Pairing them produced a system with no weak link. That
reasoning belonged to a period when Triple DES was still a live option, so SHA-224 is now
mostly a compatibility function.

For file verification specifically there is no argument for it: SHA-256 costs the same,
produces four more bytes, and is what everyone publishes.

## Matching the command line

`sha224sum file` and `shasum -a 224 file` both produce the value shown above. Paste either
tool's whole output line into the comparison box — the filename is ignored.
