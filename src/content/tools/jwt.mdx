## What a JWT is

Three Base64URL segments separated by dots:

```
eyJhbGciOiJIUzI1NiJ9  .  eyJzdWIiOiIxMjM0In0  .  signature
      header                   payload              signature
```

The first two are JSON. The third is a signature over the exact bytes of the
first two — `header.payload`, with the dots and no reformatting — computed under
the algorithm named in the header.

Everything above the signature is therefore public. Base64URL is encoding, not
encryption: the payload of any token can be read by anyone who has it. What the
signature adds is that it could not have been *changed*.

## What this page checks

Decoding is separate from verifying, and the page keeps them that way round: the
header and payload are shown whether or not the signature is, because reading a
token is a legitimate thing to do with a token you do not trust yet.

Verification uses the Web Crypto API:

- **HS256, HS384, HS512** are MACs, so they need the shared secret that signed
  it. The secret is not in the token and cannot be recovered from it.
- **RS256/384/512, PS256/384/512** are RSA signatures, checked with a public key.
- **ES256/384/512** are ECDSA, checked with a public key. JWS writes ECDSA
  signatures as r and s concatenated, which is also what the Web Crypto API
  takes — the conversion that trips people up goes the other way, from DER.

A PEM block (`-----BEGIN PUBLIC KEY-----`) and a JWK are both accepted, because a
JWK is what a JWKS endpoint publishes.

## The things that go wrong

- **`alg: none`**, and tokens with an empty signature: reported as unverifiable.
- **Algorithm confusion**, where a token is checked under the algorithm in its own
  header. The result here names the algorithm it used, so a mismatch is visible.
- **Expiry.** `exp`, `iat` and `nbf` are seconds since the epoch, and the page
  reads them as dates *and* as distances: "expired 3 days ago" is the form that
  answers the actual question. A token can verify and still be expired; expiry is
  a separate check and a relying party has to make it.
- **Whitespace.** Reformatting the JSON changes the bytes the signature covers.
  A token that was pretty-printed somewhere in transit will not verify.
