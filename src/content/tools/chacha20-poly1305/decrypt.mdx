    a: >-

  - q: >-
        The ciphertext is shorter than 16 bytes.
    a: >-
        Then it is not ChaCha20-Poly1305 as this page understands it. The tag is 16 bytes; a message of n bytes encrypts to n + 16.

## Decrypting ChaCha20-Poly1305

Paste the ciphertext with the 16-byte tag on the end, the 32-byte key, the
12-byte nonce, and any associated data that was authenticated. If the tag
verifies, the plaintext is returned. If it does not, nothing is — not a
partial message, not a padding error, not a guess.
